# B2 courses — plan

B2 mirrors B1: **26 lessons** (`b2-l1` … `b2-l26`, 9 modules of ~3), B2 **special courses**, and **Goethe + telc B2 exam prep**.
`Level` already allows `'B2'`; the learning path, statistics and specials hub already render a B2 tier.

## Source note
Hueber's *Menschen* series stops at B1 (B1.1 / B1.2), so there is no Menschen B2 coursebook to follow. The B2 curriculum
below follows the CEFR B2 descriptors and the Goethe-Zertifikat B2 / telc Deutsch B2 test specifications. All audio is
TTS (`ttsText`) — there are no official tracks.

## Phases (one PR each)
1. **Wiring + lessons 1–9** — extend level-typed code to B2 (assist route, write editor, speak pool, exam level enum), add lessons.
2. **Lessons 10–26**.
3. **B2 special courses** (new `levels: [..., 'B2']` specials, plus B2 ranges on existing ones where fitting).
4. **Exam prep**: Goethe B2 + telc B2 formats and practice sets (Lesen, Schreiben, Sprechen), same structure as B1.
5. **Audio**: `npm run audio` for all new `ttsText` (needs internet; run locally or in a networked session).

## Per-lesson template (same as B1)
`intro` → ~10–14 `vocab` → 1–2 `grammar` → ~10–12 `exercise` (mixed types, incl. `listenChoose` with `ttsText`) → `pronunciation` → `wrapup`.
Ids: lesson `b2-l{n}`, items `b2l{n}-…`, exercises `b2l{n}-e{k}`. English + French on every learner-facing field.
